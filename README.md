## 📌 Sobre o Projeto

Este repositório contém o estudo, a documentação e a demonstração prática desenvolvidos pelo **Squad 3 - Bubbles** sobre o tema **CSS Transitions**.

As transições em CSS permitem suavizar a mudança gradual entre dois estados de um elemento web (por exemplo, ao passar o mouse com `:hover`, ao alternar o foco com `:focus` ou ao modificar classes via JavaScript) ao longo de um período de tempo determinado, criando interfaces mais dinâmicas e agradáveis para o usuário.

## Conteúdo da apresentação de slides:

* Curvas de Aceleração (`transition-timing-function`)

* Gatilhos Dinâmicos Via JavaScript

## 🧪 Desafio Prático

Como parte da apresentação, foi desenvolvida uma demonstração interativa comparando dois elementos lado a lado:

1. **Elemento Sem Transição**: Altera a cor de fundo, a sombra e a elevação de forma instantânea e brusca ao passar o mouse (`:hover`) ou focar via teclado (`:focus-visible`).
2. **Elemento Com Transição**: Aplica alterações graduais e suaves na cor de fundo, na sombra projetada e no deslocamento vertical (`transform: translateY()`), demonstrando a melhoria na experiência do usuário (UX).
